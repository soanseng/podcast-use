# Edit modes

Lock one mode after inventory. Switch only with explicit user consent.

## `cleanup`

**Intent:** remove dead air, fillers, false starts, throat clears, obvious slips.

**Do:**

- Prefer safe, reversible cuts
- Preserve cadence, jokes, emotional beats
- Show estimated time saved

**Don't:**

- Restructure story order
- Start reels/cover work unless asked

**Done when:** user accepts preview and final audio renders.

## `shorten`

**Intent:** hit a target length or remove digressions.

**Do:**

- Separate *must-keep*, *optional*, *cut-first* content
- Protect thesis, stories, and payoffs
- Give before → after duration estimate

**Don't:**

- Evenly “shave” every pause into robotic pacing
- Drop context that makes later lines unreadable

## `clip`

**Intent:** extract one idea that stands alone.

**Do:**

- Start with a hook, end on a complete thought
- Prefer 30–90s for social, longer only if asked
- Offer title/hook line options

**Don't:**

- Export a fragment that needs prior context to make sense

## `takes`

**Intent:** choose the best delivery among multiple takes/files.

**Do:**

- List takes with time ranges + transcript snippets
- Recommend one primary take per line, with rationale
- Build a merged chronological EDL across sources

**Don't:**

- Assume file order equals final narrative order

## `review-only`

**Intent:** advise without writing an EDL or rendering.

**Do:**

- Content brief, structure map, risk notes
- Optional cut tiers as recommendations only

**Don't:**

- Create `edl*.json` or render audio unless user upgrades mode

## `publish`

**Intent:** ship-ready package after a locked edit.

**Required sequence:**

1. Finish and approve edit (or confirm existing approved EDL)
2. Final audio
3. Subtitles
4. Covers / YouTube video
5. Reels (ask count + style)
6. Show notes, timestamps, description

**Don't:**

- Generate packaging assets from a draft edit that may still change
